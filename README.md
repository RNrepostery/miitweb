# miitweb

MIIT Robo AI Preschool - Web Portal & Websites

This project contains:
- **`index.html`**: Dual website selector with interactive preview and launch buttons
- **`MIIT Robo AI Preschool.html`**: Website 1 (Lightweight & Compact Edition)
- **`MIIT_robo_ai_preschool_website.html`**: Website 2 (Complete Showcase Edition with rich interactive sections)

The main page loads its Tailwind styles locally from `styles.css`. After changing
Tailwind classes in `index.html`, run `npm install` once and `npm run build:css`
to regenerate that stylesheet.
